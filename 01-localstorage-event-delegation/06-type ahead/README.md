# 06 – Type Ahead

## Project Overview
This project is part of the JavaScript30 challenge by Wes Bos.

The goal is to build a Type Ahead search feature that displays matching cities and states as the user types.

## What I Learned
- Working with JavaScript Fetch API.
- Using Promises and `.then()`.
- Handling asynchronous data.
- Filtering arrays with `.filter()`.
- Using regular expressions.
- Updating the DOM dynamically.
- Highlighting matching search results.

## Technologies Used
- HTML5
- CSS3
- JavaScript

## Key Features
- Real-time search suggestions.
- Dynamic filtering of city and state names.
- Highlighted matching text.
- Data retrieved asynchronously.

## What I Practiced
This project helped me understand how JavaScript can retrieve external data and display relevant results dynamically without refreshing the page.
